# Codex Beacon v1.0.9

## 更新内容

- 移除对 Codex Desktop 内置 CLI 版本号的硬编码门禁，改由共享 socket、App Server 协议握手和已加载的 Desktop 运行态证据共同验证兼容性。
- 当共享 daemon 可连接但暂时缺少已加载的 Desktop 任务证据时，状态安全降级为“监测不可用”，同时保留已经成功读取的账户额度信息。
- 增加上述运行态证据缺失场景的自动化测试，并修复 macOS 与 GitHub Actions 测试稳定性问题。

## 安装要求

- macOS 15 或更高版本
- Apple Silicon Mac
- 已在本机安装 Codex Desktop

本版本仍为 ad-hoc 签名、未公证的 Apple Silicon 构建。首次打开时，如 macOS 显示未认证开发者提示，请按系统安全设置中的确认流程操作。
